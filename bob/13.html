Tarmoq va internet

Telegram'dagi bitta xabar telefondan routerga, provayderga, magistralga va serverga yetguncha to'rt qatlamdan o'tadi va har qatlam unga o'z konvertini kiydiradi.

Bugungi kompyuter deyarli har doim tarmoqqa ulangan. Internet — bu millionlab tarmoqlarning bir-biriga ulangan global tarmog'i. Ma'lumotlar uzatilishi uchun barcha qurilmalar umumiy qoidalarga — protokollarga amal qiladi. Protokollar qatlamlarga ajratilgan va har bir qatlam o'z vazifasini bajaradi.

13.1. Tarmoq qatlamlari

Kanal qatlami (Wi-Fi, Ethernet) — bitlarni bitta fizik ulanish orqali, masalan, telefondan routergacha uzatadi. Har bir tarmoq kartasining noyob MAC manzili bor. Tarmoq qatlami (IP) — paketni butun internet bo'ylab manzilga yetkazadi. Har bir qurilmaning IP manzili bor (masalan, 185.199.108.153). Routerlar paket manzilini ko'rib, uni keyingi routerga uzatadi — xuddi pochta bo'limlari xatni shahardan shaharga uzatgandek. Transport qatlami — TCP ma'lumotning to'liq va to'g'ri tartibda yetib borishini kafolatlaydi (yo'qolgan paketlar qayta yuboriladi); UDP esa kafolatsiz, lekin tezroq (video qo'ng'iroqlar, o'yinlar). Shuningdek bu qatlamda port raqamlari ishlatiladi — bitta kompyuterdagi turli dasturlarni ajratish uchun (HTTPS — 443, PostgreSQL — 5432). Ilova qatlami — HTTP, HTTPS, WebSocket, Telegram'ning MTProto protokoli kabi aniq dasturlar tushunadigan formatlar.

13.2. DNS

Odamlar uchun api.telegram.org kabi nomlarni eslab qolish oson, kompyuterlar esa IP manzillar bilan ishlaydi. DNS (domen nomlari tizimi) — internetning "telefon kitobi". Brauzerda sayt nomini yozganingizda, kompyuter avval DNS serveridan uning IP manzilini so'raydi, keyin shu manzilga ulanadi. Siz bot uchun domen sotib olib, uni server IP manziliga yo'naltirganingizda aynan DNS yozuvini (A record) sozlaysiz.

13.3. HTTPS va shifrlash

Internetdagi ma'lumot ko'plab routerlar orqali o'tadi va ularning har birida uni o'qish mumkin. Shuning uchun maxfiy ma'lumotlar shifrlanadi. HTTPS — HTTP ustiga TLS shifrlash qo'shilgan protokol. Ulanish boshida brauzer va server ochiq kalitli kriptografiya yordamida xavfsiz tarzda umumiy maxfiy kalit kelishib oladi, so'ng barcha ma'lumotlar shu kalit bilan shifrlanadi. Serverning haqiqiyligi sertifikat orqali tasdiqlanadi (masalan, Let's Encrypt bepul sertifikat beradi). Telegram Mini App'lar faqat HTTPS orqali ishlashi ham shu sababli.

13.4. Mijoz-server modeli

Internetdagi ko'p xizmatlar mijoz-server modelida ishlaydi. Mijoz (brauzer, mobil ilova) so'rov yuboradi, server uni qayta ishlab, javob qaytaradi. Server — bu ham oddiy kompyuter, faqat u doimiy yoqiq turadi, doimiy IP manzilga ega va so'rovlarni kutib turuvchi dastur (masalan, Node.js yoki Nginx) ishlab turadi. Telegram bot misolida: foydalanuvchi xabar yozadi → Telegram serverlariga boradi → Telegram uni webhook orqali sizning serveringizga HTTPS so'rov sifatida yuboradi → botingiz ma'lumotlar bazasiga murojaat qilib, javob tayyorlaydi → Telegram API orqali javob foydalanuvchiga qaytadi. Bu butun zanjir odatda 100-300 millisekund ichida bajariladi.
